# The Impact-Weighted Ferry

An electric ferry saves its owner money. It saves the rest of us more.

**Live:** https://suvashgiri.github.io/impact-weighted-ferry/

A one-page explainer: what one Norwegian battery ferry is worth in a year when the CO₂ it avoids is counted in money, and who captures that value – suppliers, the operator, or society.

Built from public sources: Siemens/Bellona fleet study (84 battery ferries), IFVI/VBA GHG methodology, Torghatten and Maritimt Magasin (MF Hinnøy). Illustrative averages, not any operator's accounts. Climate impact only.

Independent project by Suvash Giri, built with an AI assistant. Not affiliated with or endorsed by Summa Equity, IFVI, Torghatten or any ferry operator.
